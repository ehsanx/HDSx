# Assignment 10: Portfolio Surgery and Reproducibility Test

## Purpose

Stress-test your final project in a fresh environment, repair reproducibility failures, and document remaining risks before portfolio submission.

## Inputs

- Dataset: `examples/nhanes-equity/data/nhanes_equity_v6.csv`
- Reproducibility protocol: `weeks/week11-portfolio-surgery/reproducibility-test.qmd`
- Static dashboard exemplar: `weeks/week11-portfolio-surgery/static-dashboard-ojs.qmd`

## Step-by-Step Tasks

1. Open your repository in a fresh Codespace or equivalent clean environment.
2. Follow only the README and documented setup instructions.
3. Render your report or book.
4. Run or render the required dashboard artifact.
5. Check relative paths, package loading, citations, data availability, and AI-use notes.
6. Log each failure and repair.
7. Commit fixes with clear messages.
8. Write a final risk note for any issue that remains.

## What To Submit

Place all submission files in:

```text
assignments/assignment10-portfolio-surgery/submission/
```

Submit these files:

- `reproducibility-test.md`: completed failure log and repair notes.
- `final-risk-note.md`: remaining risks or a statement that no known risks remain.
- `repair-summary.md`: list of files changed during the reproducibility repair.
- Link to the commit or pull request containing the repairs.

## Submission Route

Submit a Canvas assignment entry that contains a link to the repository folder `assignments/assignment10-portfolio-surgery/submission/` and the final repair commit or pull request.

## Grading Checklist

Complete:

- Fresh-environment test was performed.
- Failures and fixes are documented.
- README instructions match the tested workflow.
- Relative paths work.
- Required outputs render or run.
- Remaining risks are explicitly documented.

Needs work:

- Test was performed only in the original working environment.
- Failure log is missing or vague.
- Fixes are not committed.
- README remains inaccurate.
- Required outputs cannot be reproduced.

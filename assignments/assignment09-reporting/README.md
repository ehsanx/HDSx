# Assignment 9: Reproducible Report

## Purpose

Create a short Quarto report that complements the NHANES Equity Dashboard. The report should fix one question, regenerate its outputs from code, cite the data source, and state limitations clearly.

## Inputs

- Dataset: `examples/nhanes-equity/data/nhanes_equity_v6.csv`
- Report template: `weeks/week10-reporting-publishing/report-template.qmd`
- Bibliography: `references.bib`

## Step-by-Step Tasks

1. Copy the structure of the Week 10 report template into your assignment folder.
2. Define one descriptive question using the NHANES Health Equity CSV snapshot.
3. Load the dataset with a relative path.
4. Produce at least one table and one figure from code.
5. Cite CDC/NCHS NHANES using the bibliography workflow.
6. Write a limitations section that avoids causal overclaiming.
7. Add an AI-use and audit note.
8. Render the report and review the HTML output.

## What To Submit

Place all submission files in:

```text
assignments/assignment09-reporting/submission/
```

Submit these files:

- `report.qmd`: rerunnable Quarto report.
- `report.html`: rendered report.
- `figures/` or `outputs/`: any generated images or tables if your report writes external files.
- `ai-use-note.md`: what AI helped draft and how you checked it.

## Submission Route

Submit a Canvas assignment entry that contains a link to the repository folder `assignments/assignment09-reporting/submission/`.

## Grading Checklist

Complete:

- Uses the canonical NHANES CSV path or a clearly documented relative copy.
- Report renders without manual steps.
- Includes one code-generated figure and one code-generated table.
- Citations resolve through `references.bib`.
- Limitations are visible and non-causal.
- AI-use note is present.

Needs work:

- Uses absolute paths.
- Outputs are pasted rather than regenerated by code.
- Citation is missing or unresolved.
- The report duplicates the dashboard without adding methods, limitations, or source context.
- The report does not render.

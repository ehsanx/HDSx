## 📖 About the Project

**Health Data Science: AI and Knowledge Translation** is an open educational resource (OER) designed to bridge the gap between traditional epidemiology and modern data science. 

Unlike standard textbooks that focus on a single tool, this project adopts a **"Polyglot" approach**—teaching **R** and **Python** side-by-side—and integrates **Generative AI** directly into the research workflow. It is built to take learners from "Zero to AI Co-Pilot," teaching them to use LLMs to generate, debug, and audit code while maintaining rigorous scientific standards.

This resource is open to self-paced learners worldwide.

## 🚀 Key Features

* **Polyglot Workflows:** Every concept is implemented in both **R** (Tidyverse) and **Python** (Pandas/Scikit-Learn).
* **AI-First Pedagogy:** Learn to use AI Co-Pilots (GitHub Copilot, ChatGPT) to write and audit code.
* **Real-World Data:** No "toy" datasets. We use open health data from **NHANES**, **WHO**, and **Kaggle**.
* **Knowledge Translation:** dedicated modules on building interactive dashboards (Shiny/Dash) and dynamic reports.
* **Data Sovereignty:** Practical frameworks for **Data Sovereignty** principles.

## 📚 Curriculum Structure

The content is organized into 11 modular chapters:

1.  **Health Data & Ethics** – Open data sources & Data Sovereignty.
2.  **The Digital Lab Notebook** – Setting up reproducible cloud environments.
3.  **R with AI** – Mastering R fundamentals with an AI debugger.
4.  **Git & Team Collaboration** – Version control for research teams.
5.  **Python with AI** – Setting up Python and translating R code.
6.  **Visual Storytelling** – Principles of design with ggplot2 & Altair.
7.  **Exploring Data** – Cleaning messy health data & documenting decisions.
8.  **Interactive Dashboards** – Building web tools with R Shiny & Python Dash.
9.  **Dynamic Presentations** – Creating auto-updating slides with Quarto.
10. **Reproducible Reporting** – Automated manuscript generation.
11. **Advanced Topics** – Introduction to Cloud Computing.
